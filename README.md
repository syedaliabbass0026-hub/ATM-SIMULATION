# ATM-SIMULATION
ATM Simulation is a software program that copies the functions of a real ATM machine. It allows users to perform banking tasks like cash withdrawal, balance checking, deposits, and money transfers using a virtual system. It is mainly used for learning programming and banking operations.

🏦 Purpose:
The purpose of this ATM Simulation project is to create a digital banking experience that works like a real ATM machine 💳. It allows users to securely enter a PIN 🔐 and perform banking operations such as depositing money 💵, withdrawing cash 💸, checking balance 📊, and viewing transaction history 📜.
This project helps in understanding programming concepts while giving a realistic banking system vibe ✨.

🎯 Objectives:
🔐 To provide secure PIN authentication for users.
💰 To perform deposit operations smoothly.
💸 To allow cash withdrawal from the account balance.
📜 To store and display transaction history.
🧠 To improve programming skills using conditions, loops, and functions.
🏦 To simulate real-world ATM banking operations in a simple way.

✨ Features:
🔑 Secure PIN login system
💵 Deposit money into account
💸 Withdraw money easily
📊 Check available account balance
📜 View complete transaction history
🖥️ Simple and user-friendly interface
⚡ Fast and smooth banking operation
