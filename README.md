# ATM-SIMULATION
ATM Simulation is a software program that copies the functions of a real ATM machine. It allows users to perform banking tasks like cash withdrawal, balance checking, deposits, and money transfers using a virtual system. It is mainly used for learning programming and banking operations.

<!-- ================= PURPOSE ================= -->

<h2>🏦 Purpose</h2>

<ul>
    <li>💳 Simulates a real ATM banking system.</li>
    <li>🔐 Allows secure PIN-based login authentication.</li>
    <li>💵 Performs deposit and withdrawal operations.</li>
    <li>📜 Stores and displays transaction history.</li>
    <li>🧠 Helps understand basic banking and programming concepts.</li>
</ul>

<!-- ================= OBJECTIVES ================= -->

<h2>🎯 Objectives</h2>

<ul>
    <li>🔑 To create a secure ATM login system using PIN verification.</li>
    <li>💰 To allow users to deposit money into their account.</li>
    <li>💸 To enable withdrawal functionality with balance checking.</li>
    <li>📊 To display the current account balance.</li>
    <li>📜 To maintain transaction history records.</li>
    <li>⚡ To improve understanding of conditions, loops, and functions.</li>
</ul>
